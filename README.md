# 企划设计平台 V2.0 独立工程

这是按用户确认的范围重新整理的独立工程。启动、构建和源码打包只依赖本目录；不需要父目录的旧平台，也不会启动旧门户、体验中心或旧企划项目服务器。

## 目录

| 路径 | 用途 |
| --- | --- |
| `web/` | V2.0 React 前端及调度视图入口 |
| `底层能力/` | 共享组件、表格能力、离线字体及许可 |
| `backend/` | 独立身份/人员/模版 API、AI 授权代理、进程管理 |
| `baseline/` | 已统一 V2.0 视觉的十二维模版正文、样例与所需资源 |
| `services/ai-gateway/` | 保留的任务、流程、模型/员工、协作、执行器与研究适配代码 |
| `scripts/` | 仅本工程使用的构建、启动与打包入口 |
| `tests/` | 独立后端与浏览器验收入口；调度单测在服务目录 |

没有 `modules/bg`、`modules/experience`、`modules/capabilities` 或旧 `portal`。模版正文和调度任务控制器保留可用业务代码，属于 V2.0 正在使用的资源，不是另一套旧版平台界面。源码复用和裁剪范围见 [工程边界](docs/工程边界.md)。

## 启动

需要 Python 3.12+、Node.js 22.18+ 与 npm。后端仅使用 Python 标准库；调度服务使用 Node 标准库。首次构建需下载前端锁定依赖。

```sh
python3.12 scripts/build.py
python3.12 scripts/run.py --port 8780
```

macOS 可双击 `启动V2.0.command`；Windows 可双击 `启动V2.0.bat`（确保 `python` 为 3.12+）。打开启动终端输出的本机网址，根路径直接进入 V2.0。默认端口如被占用，请使用独立端口，例如 `--port 8793`。

macOS 双击入口使用 8793 端口：已有服务提供本工程当前构建时，直接打开网页；否则先构建、启动，再在首页与调度入口就绪后自动打开浏览器。新启动的服务需要保留终端窗口，按 Ctrl+C 停止。端口占用或启动失败会在终端明确提示；不会停止其他服务或重置数据。

首次启动空数据目录会生成管理员临时密码，只在终端显示一次，首次登录必须修改。重启不重置已有账号。数据默认保存在本目录 `data/`，每人独立调度实例；也可显式传 `--data-dir /另一个目录`。同一数据目录不允许两个启动器同时使用。源码包不包含数据和密码，不会自动读取原平台数据。

前端开发：在 `web` 内执行 `npm ci`、`npm run dev`，默认代理到 8780 后端；其他端口可设置 `VITE_PLATFORM_TARGET=http://127.0.0.1:8793`。正式构建由独立后端在同站点提供 `web/dist`，无需旧启动器或外部反向代理。退出终端会停止本启动器的调度子进程。

## 当前范围

独立工程包含当前已经迁移的展会情况、个人历史统计看板、模版管理、人员管理和七页调度，以及共享组件。总览仍有演示数据，其他规划菜单和部分能力演示尚未完成真实业务迁移；没有把这些页面补成新的业务系统。“独立完整工程”指源码及运行依赖自足，不代表全部规划业务已研发完成。

调度保留已有业务控制器并使用 V2.0 外壳、主题、共享控件和 Radix 弹窗；不是把任务逻辑重新写成另一套 React 状态机。保留相关原始协议有助于兼容。停用的知识库、旧独立登录和账号维护、旧安装器已移除；平台生命周期统一由本启动器管理。本批已完成指定源的展会库及个人统计历史迁入和对账；展会源为空，未填入演示记录。看板是标明截止日期的只读历史快照，完整企划项目编辑尚未迁移。真实模型、物理执行器及其他真实业务数据迁移仍需实际环境验收。迁移范围与验收见 [展会与看板迁移记录](docs/展会与数据看板迁移-20261119.md)。

校验、进度和未完成项见 [进度&规则](进度&规则.md)。打包：`python3 scripts/package_source.py`，输出干净源码 ZIP、逐文件清单和校验值；不会包含依赖、构建、数据或私有配置。
