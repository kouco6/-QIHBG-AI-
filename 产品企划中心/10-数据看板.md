# 数据看板

统计来自真实归档记录。接口没准备好时不显示示例数字。

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 归档统计 | 说明 | 始终 |
| 数据看板 | 标题 | 始终 |
| 个人企划工作量与项目完成周期。 | 说明 | 始终 |
| 时间范围 | 说明 | 筛选区 |
| 全部 / 本周 / 本月 / 本年 / 自定义 | 按钮 | 始终，默认全部 |
| 开始日期 | 输入 | 只在自定义 |
| 结束日期 | 输入 | 只在自定义 |
| 核心指标 | 标题 | 有统计结果 |
| 本期完成项目数 | 说明 | 值为 {数量} |
| 本期推进中项目数 | 说明 | 值为 {数量} |
| 平均完成周期 | 说明 | 值为 {天数} 天 |
| 项目完成趋势 | 标题 | 始终 |
| 首次归档 | 说明 | 趋势图含义 |
| 首次归档数量 | 说明 | 柱形提示为「{时间}：{数量}」 |
| 该范围内没有首次归档 | 说明 | 趋势为空 |
| 本期完成项目 | 标题 | 始终 |
| 项目名称 / 创建日期 / 首次归档日期 / 首次完成周期 | 表头 | 完成项目表 |
| 本期推进中项目 | 标题 | 始终 |
| 项目名称 / 创建日期 / 最近有效推进日期 / 已进行天数 | 表头 | 推进中项目表 |
| 正在读取统计… | 状态 | 加载中 |
| 重新加载 | 按钮 | 读取失败 |
| 统计结果不可用 | 标题 | 读取失败 |
| 统计接口尚未就绪，暂不显示示例数 | 说明 | 接口未接通 |
