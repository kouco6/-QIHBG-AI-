# 企划项目

## 有项目

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 企划项目 | 标题 | 始终 |
| 在用 {数量} 个。进入项目后继续研究、编辑和正式应用。 | 说明 | 始终。数量只统计在用项目 |
| ＋ 新建企划项目 | 按钮 | 始终 |
| 在用项目 | 按钮 | 始终，默认选中 |
| 已归档项目 | 按钮 | 始终 |
| 搜索产品名称… | 输入 | 始终，名称为「搜索产品名称」 |
| 最近更新 | 选择 | 始终，默认 |
| 按名称排序 | 选择 | 始终 |
| 产品名称 | 表头 | 有项目 |
| 产品类型 | 表头 | 有项目 |
| 已应用 | 表头 | 有项目 |
| 最近更新 | 表头 | 有项目 |
| 项目管理 | 表头 | 有项目 |
| {产品名称} | 按钮 | 有项目，整行进入项目 |
| 在用 / 已归档 | 状态 | 随项目状态 |
| 单品 / 系统 | 状态 | 随产品类型 |
| {已应用数}/12 | 状态 | 有项目 |
| {更新时间} | 说明 | 无时间时为 — |
| 归档 / 恢复 | 按钮 | 在用显示归档，已归档显示恢复 |
| 删除 | 按钮 | 有项目 |

## 空列表

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 还没有企划项目 | 标题 | 在用且没有搜索词 |
| 在此开始建立新的产品企划项目。 | 说明 | 同上 |
| 新建项目 | 按钮 | 同上 |
| 暂无已归档项目 | 标题 | 归档筛选且没有项目 |

| 请调整关键词或筛选条件 | 说明 | 搜索无结果 |

## 归档、恢复、删除

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 归档项目 / 恢复项目 / 永久删除 | 标题 | 对应操作 |
| 目标项目：{产品名称} | 说明 | 始终。项目不存在时为「不存在」 |
| 项目ID：{编号}　·　类型：{单品或系统} | 说明 | 始终 |
| 归档保留正文、研究任务、原始MD和历史版本，并从在用列表隐藏；恢复使用原projectId。 | 说明 | 归档或恢复 |
| 将永久删除本机平台中的项目、12维度正文、研究周期及历史版本。已导出的HTML和平台外文件不会自动删除。 | 说明 | 删除 |
| 输入“确认删除”继续 | 输入标签 | 删除 |
| 确认删除 | 输入占位 | 删除，必须原样输入才能继续 |
| 取消 | 按钮 | 始终 |
| 归档项目 / 恢复项目 / 永久删除 | 按钮 | 与标题相同，删除为危险按钮 |
