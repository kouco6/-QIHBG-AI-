## 六章字段

每章末尾都有「补充资料与待整理正文」。信息状态是：未填写、未查到、不适用、已填写。数据性质是：直接引用／人工分析、人工估算。估算时另有「估算依据」。来源有来源名称、来源链接、来源发布日期。

行业概况：定义行业边界，理解技术、资质与政策背景。

| 文字 | 属性 |
| --- | --- |
| 行业定义 | 输入 |
| 发展历程 | 表。列：日期／时期、事件、说明 |
| 产品分类 | 表。列：分类名称、说明 |
| 核心技术 | 表。列：技术名称、说明 |
| 资质认证 | 表。列：类型（公司资质、产品认证）、资质／认证名称、条件、费用（含币种及单位）、必要性 |
| 发展趋势 · 技术需求 | 输入 |
| 发展趋势 · 市场趋势 | 输入 |
| 政策背景 | 表。列：政策名称、发布日期、影响（利好、利空）、主要内容 |
