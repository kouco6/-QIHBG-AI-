## 新增与编辑

必填项标 *。标题是「新增展会」或「编辑展会」。说明是「保存后更新 BG 共享展会库，* 为必填项。」

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 展会名称 * | 输入 | 始终 |
| 推荐分组 | 选择 | 强相关 / 推荐 / 不相关 |
| 推荐度 | 选择 | 未填写、一星到五星 |
| 展会分类 / 行业 | 输入 | 始终 |
| 级别 | 输入 | 始终 |
| 专题标签（可多选） | 选择 | 已有专题；没有时为「暂无专题，可在下方新增。」 |
| 输入新的专题名称 | 输入 | 名称为「新专题名称」 |
| 添加专题 | 按钮 | 始终 |
| 展期标记 | 选择 | 正常 / 延期 / 取消 / 日期待定 |
| 延期但新日期未知时，清空起止日期；已知新展期时填写新日期。 | 说明 | 始终 |
| 开始日期 / 结束日期 | 输入 | 日期 |
| 城市 | 输入 | 始终 |
| 展馆 * | 输入 | 始终 |
| 推荐理由 / 主要内容 / 参展商 | 输入 | 多行 |
| 展览面积 / 观众数量 / 参展商数量 / 官网 | 输入 | 始终 |
| 可选信息可稍后补充 | 说明 | 新增 |
| 修改不会影响其他展会 | 说明 | 编辑 |
| 取消 | 按钮 | 始终 |
| 保存展会 | 按钮 | 始终 |
| 放弃当前修改并重新打开吗？ | 说明 | 有未保存修改时再次打开 |
