# 项目概览

打开一个企划项目后的页面。三个页签共用同一条页头。

## 页头

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 产品企划 / {单品或系统} | 说明 | 始终 |
| {产品名称} | 标题 | 始终 |
| 研究、编辑和正式应用在这个项目里衔接。确认更新后才写入编辑内容。 | 说明 | 始终 |
| ← 企划项目 | 按钮 | 从项目列表进入 |
| ← 数据看板 | 按钮 | 从数据看板进入 |
| 查看研究成果 | 按钮 | 始终，进入 DIM-03 研究流程 |
| 企划报告 | 按钮 | 始终 |
| 发起研究 | 按钮 | 始终。研究进行中不可点 |
| 项目概览 | 按钮 | 页签，默认选中 |
| 12维企划 | 按钮 | 页签 |
| 研究任务 {数量} | 按钮 | 页签。数量是已有研究状态的维度数 |
| 项目不存在或已删除。 | 说明 | 项目已被删除 |
| 返回项目列表 | 按钮 | 项目已被删除 |

## 项目概览

阶段状态按顺序只显示一种：研究进行中、成果待确认、编辑与正式应用、尚未开始。

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 已应用正式内容 | 标题 | 始终 |
| {阶段状态} | 状态 | 始终 |
| {已应用数} / 12 维 | 状态 | 始终 |
| 未正式应用的内容不会进入预览和报告 | 说明 | 始终 |
| {百分比}% | 状态 | 始终 |
| 项目信息 | 标题 | 始终 |
| 产品类型 | 说明 | 值为 {单品或系统}，没有时为 — |
| 最近更新 | 说明 | 值为 {更新时间} |
| 研究成果 | 说明 | 「{数量} 项待确认」「进行中」或「暂无待确认成果」 |
| 继续完善企划 | 标题 | 始终 |
| 全部维度 | 按钮 | 切到 12维企划 |
| {DIM-编号} | 说明 | 维度卡片 |
| {维度名称} | 按钮 | 进入该维度 |
| 待确认 / {研究状态} / 研究失败 / 已应用 / 待完善 | 状态 | 每张卡片一种 |
| 研究成果等待确认 | 标题 | 有待确认成果 |
| 先查看研究内容，再决定是否确认更新工作稿。 | 说明 | 有待确认成果 |
| 研究尚未结束 | 标题 | 有进行中的研究 |
| 状态以后端返回为准，页面不会提前写成已完成。 | 说明 | 研究进行中 |
| 还没有待确认的研究成果 | 标题 | 其余情况 |
| 发起研究后，这里只显示真实任务。 | 说明 | 其余情况 |

## 12维企划

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 维度工作区 | 标题 | 该页签 |
| 点进去继续编辑 | 状态 | 该页签 |
| 十二张维度卡片 | 按钮 | 与概览卡片相同，十二维全部列出 |

## 研究任务

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 研究任务列表 | 标题 | 该页签 |
| 筛选研究任务 | 说明 | 筛选区名称 |
| 全部任务 / 待确认 / 处理中 / 未开始 / 研究失败 | 按钮 | 筛选 |
| 发起研究 | 按钮 | 始终 |
| 研究全部12维 | 按钮 | 始终 |
| 全部同步W | 按钮 | 本轮有可同步成果 |
| 没有待同步的研究成果 | 按钮 | 没有可同步项，不可点 |
| 本轮研究尚未全部结束 | 按钮 | 仍有进行中的任务，不可点 |
| 刷新状态 | 按钮 | 始终 |
| 研究任务 | 表头 | 始终 |
| 状态 | 表头 | 始终 |
| 成果 | 表头 | 始终 |
| 操作 | 表头 | 始终 |
| 共 {数量} 项 | 说明 | 始终 |
| 状态以后端返回为准 | 说明 | 始终 |
| 这个筛选下没有研究任务。 | 说明 | 筛选结果为空 |
| 正在等待调度中心返回，页面不会提前显示研究已开始。 | 说明 | 刚提交、尚未收到任务 |

维度内的研究流程页会加一句：「维度内的研究步骤。项目级研究任务在项目页「研究任务」。」

## 发起研究

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 发起专业研究 | 标题 | 弹层 |
| {产品名称} | 说明 | 弹层，没有项目时为「当前项目」 |
| 研究范围 | 选择 | 当前维度 / 全部 12 维 |
| 研究维度 | 选择 | DIM-编号 · 维度名称 |
| 补充研究要求 | 输入 | 占位：补充需要关注的资料范围或项目背景… |
| 提交后会请求调度中心。页面在收到真实任务前不会显示研究已开始。选择全部 12 维时会逐项提交。未配置专业技能的维度会返回真实失败，不会用示例内容代替。 | 说明 | 没有单独能力说明时使用这段 |
| 取消 | 按钮 | 弹层 |
| 确认发起 | 按钮 | 弹层 |

## 确认更新

| 文字 | 属性 | 出现状态 |
| --- | --- | --- |
| 确认更新W | 标题 | 同步单个维度 |
| 是否将本次研究成果写入「{维度名称}」的编辑内容？系统会保留原有内容的历史版本，方便后续恢复。 | 说明 | 单个维度 |
| 更新编辑内容不等于保存草稿，也不等于保存并应用。 | 说明 | 单个维度 |
| 确认更新W | 按钮 | 单个维度 |
| 全部同步W | 标题 | 同步全部可更新维度 |
| 只同步本轮已经研究完成、且尚未同步的维度。已同步和未完成的维度会跳过，不会用更早的成果补齐。系统会保留各维度原有内容的历史版本。 | 说明 | 全部同步 |
| 全部同步W | 按钮 | 全部同步 |
| 取消 | 按钮 | 两种弹层都有 |
