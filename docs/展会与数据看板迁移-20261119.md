实施开始：2026-11-19；跨日收尾：2026-11-20（Asia/Shanghai）。用户经 grilling 确认后实施。

## 确认范围与实现

一次性迁入，V2 独立运行。展会保留共享库、月度/待定/归档、推荐/专题/城市/行业筛选、搜索、列表/月历、详情、新增编辑、Excel导入、归档恢复、专题及维护人员。普通账号只读，指定维护者可写，管理员管理维护人员；每次 API 读写通过独立身份服务校验会话、启用状态、强制改密和企划授权。保留 revision 冲突保护、重复导入跳过和不覆盖人工修改的规则。

看板仅提供当前账号的历史个人统计及只读详情，不迁入完整企划项目编辑业务。修复旧 UI 的 range/扁平字段与后端 period/嵌套字段不兼容；统一使用 `/platform/v2/planning-dashboard?period=all|week|month|year|custom`。全部为默认；自定义为包含首尾日期的业务日区间；周/月/年按钮以当前业务日期筛选，计算始终截到快照，不模拟新事件。

保留可信首次归档、有效保存/恢复推进、删除项目全部时期排除、完成与推进中可重叠、缺少可信样本返回 null 显示“—”、未知历史不推算等口径。统计截止、已进行天数固定到迁移快照。无当前账号快照时返回不可用状态，不展示示例数。

接口及运行均只依赖本工程。展会存储逻辑来源于旧 `scripts/platform_exhibitions.py`；看板计算来源于旧 `modules/bg/planning_dashboard.py`，在本工程修复契约及全部时间范围，并适配只读投影。没有启动或引入旧企划服务器、门户或体验服务。

## 交互

新 React 页面直接组合 `@capability-ui/*`；展会和两张统计明细复用 `@capability-table/data-table`。详情使用 Sheet，编辑/专题/人员/导入结果使用 Dialog。编辑弹窗固定标题和不透明操作区，中间使用独立容器滚动（避免原生fieldset内容穿透操作区）；未保存编辑支持离开确认及 beforeunload 提示。保留业务状态文字、归档恢复确认和完整导入逐行结果。

趋势复用共享 Chart/Recharts，时间范围采用已落地 React Bits RubberSegment，使用 V2 主题变量及减弱动画支持。未从外部注册源引入新依赖。新增 `#planning/exhibitions` 和 `#planning/dashboard` 直达/刷新及同页 hash 导航。
