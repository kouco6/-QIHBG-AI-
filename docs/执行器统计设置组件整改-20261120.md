# 执行器、统计与设置组件整改（2026-11-20）

本批按任务执行及协作资源库的既有整改方式，先盘点共享组件，再修改业务组合；不新增规划业务、第二套身份体系或执行协议。

## 组件盘点与实际接入

| 范围 | 发现的问题 | 本批实现 |
| --- | --- | --- |
| 执行器 | 手写卡片、旧背景和小字号；最近任务容易被固定按钮高度影响；空态仍指向旧Token入口 | 共享Card承载原控制器节点；最近任务使用ActionCard/Button，内容决定高度；目录、版本、状态长文本换行，运行/配置窄屏单列；V2空态统一配置码连接 |
| 统计 | 手写表格，缺少通用表格的分页、列管理和局部横向滚动 | 接入`@capability-table/native-data-table`，实际使用同一个DataTable/Table/Button/Select/Checkbox/DropdownMenu；保留原聚合口径，补齐空态和读取失败反馈 |
| 设置概览 | 旧事实格小字、挤压、主题不一致 | 共享统计Card；四列/两列/单列响应布局，网关在线/异常保留语义色 |
| 我的模型/员工 | 自制卡片、标签和操作条，长名称/模型/地址容易挤出 | 真实Card/Badge/Button/Avatar组合，操作常显，状态明确；原API和事件回调保留；地址/上游模型支持换行 |
| 设置分组 | 折叠标题小字、说明截断、分组间隔紧 | 共享Card包裹既有details节点，保留open状态和原生键盘折叠；业务只调整标题/正文间距、换行和响应排列 |
| 配置码/目录/模型/员工弹窗 | 动态表单需统一尺寸及焦点行为 | 继续使用共享Radix Dialog、Input/Textarea样式桥接及Select/Checkbox；固定标题/操作区、正文滚动；补齐重绘后按稳定标识或ID回焦 |
| V2工程边界 | 嵌入设置仍渲染旧网关人事/监听/停服/更新控件，其中部分已被后端禁用 | V2嵌入页移除这些重复运维入口，不请求对应分组数据；身份统一由平台人员管理负责，进程与源码更新由独立启动器负责 |

现有组件与已安装的shadcn/Radix依赖覆盖需求，本批没有新增第三方依赖或复制通用实现。折叠保留原生details协议，共享Card负责表面；原生业务表单继续保留节点和值，通过共享桥接接入，不改成第二套业务状态机。

共享改动：`native-collections`增加头像和成功/异常语义状态；短生命周期统计Card释放React root；`native-action-cards`提供稳定回焦标识；`native-dialog`支持触发节点重绘后回焦。表格桥接支持调用方提供空态/错误文案。宿主`web/src/index.css`继续负责字体和主题，`native-layout`负责舒适控件密度，`scheduler.css`仅补业务组合及旧样式收敛。

## 数据和行为边界

统计仍读取原`/api/tasks?range=all`并按人员聚合：总数包含全部状态；完成、失败/中断、运行/排队各按原规则计数；Tokens累加既有usage，执行时长仍仅累计已完成任务。设置概览仍显示近7天数据。没有引入估算费用、虚构用量或新的统计源。

目录白名单仍通过原`runner-prefs`保存并按既有路径规则规范化；模型/员工沿用原API和数据格式。未改身份、令牌、远程执行器心跳/领取/回传或任务取消协议。未修改后端源码。
