# 协作、产出库与工作方法组件整改

日期：2026-11-20（Asia/Shanghai）。沿用任务执行流程：规则与组件盘点 → 实际组件替换 → 内容密度和主题 → 非空长文本与窄屏 → 保存及操作回归。

## 检查与整改

| 范围 | 原问题 | 本批实现 |
| --- | --- | --- |
| 三页统计与筛选 | 各自拼接统计卡、重复筛选外观及底线 | native-collections 实际组合 Card / Button；筛选使用按钮组与 aria-pressed，统一40px舒适密度 |
| 协作项目墙、项目任务 | 自建卡片，缺少统一键盘入口 | 实际 Card / Button / Badge 记录卡；保留整卡点击，标题支持键盘进入 |
| 成员、员工、动态 | 自建容器、操作仅悬停显示、长文字挤压 | 共享 Card 包裹原内容和事件；操作始终可见，长文本换行，保留状态语义 |
| 协作筛选与管理员 | 原生 select 外观不一致 | 真实共享 Select；项目和员工表单沿用共享 Dialog / Select / Checkbox |
| 产出列表 | 独立文件行，操作挤在窄列 | 复用同一个 DataTable，含文件、类型、大小、来源任务、时间和操作列；分页、排序、列显示、选择和局部横向滚动 |
| 文件预览 | 原生 HTML dialog、旧按钮高度覆盖 | 共享 Dialog 接管遮罩、焦点和Esc；保留预览节点、下载、路径与Blob清理；长文件名使用content尺寸 |
| 本机/云端方法卡 | 自建卡片、字号小、动作挤压 | 共享 Card / Badge / Button；分开内容和操作区，长标识换行 |
| 方法详情、编辑、平台连接 | 原生弹窗，表单密集 | native-retained-dialog 接入共享 Dialog；固定标题/操作区、正文滚动；正文至少280px、说明至少112px；重绘后恢复操作焦点 |
| 方法排序 | 本机显示“最新/最热”却调用云端查询，云端反而隐藏 | 仅云端显示，接入共享 Select |
| 样式污染 | 旧全局button覆盖真实组件文字颜色/字体 | 基础规则排除带data-slot的组件；删除预览按钮高度覆盖，统一宿主主题 |

已核对现有底层组件及其实现。Card、Button、Badge、Dialog、Select、Checkbox、DataTable覆盖本次需求，因此扩展共享桥接入口，没有新增外部依赖。原生输入和保留内容中的按钮继续使用现有Input / Textarea / Button样式适配；未声称所有业务DOM都重写为React。业务页面保留排布、流式内容和事件，不复制通用组件。

产出库从手工分组文件行改为统一表格，在来源列定位任务；窄屏保留表格结构并在容器内滚动。路径失效明确标注，禁用预览/下载，复制路径仍可用。
