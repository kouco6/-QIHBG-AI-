# 独立工程范围与来源

2026-11-19，用户指出上一版源码包含旧工程，明确选择“完整 V2.0 独立工程：保留必要后端，剥离旧版界面和无关模块”。

本工程保留 V2.0 前端及共享组件。身份服务沿用已有账号 ID、角色、标签、密码、会话、最后管理员等规则，但解除体验服务的账号创建/同步依赖；身份库中历史 `experience` 字段仅作为兼容的不透明标识保留，不对应运行中的体验模块。模版服务保留样例校验、不可变版本、导入/应用分离、revision 冲突保护和沙箱预览；直接使用本工程的 V2.0 基线，不再访问旧注册表或原企划服务器。模版合同中旧入口字段变为可选：既有整套包可兼容导入，新基线不携带旧兼容页面。

调度服务复用已合并的后端、任务控制器和执行器协议，保留每人独立数据及平台身份适配。旧登录文件、旧侧栏展示、独立人员维护界面、停用知识库和独立安装器被移除；V2.0 通过专用 scaffold 与布局资源加载当前业务视图。少量隐藏元素是原控制器必须的 DOM 钩子，没有旧导航或品牌展示。原研究协议、技能和任务持久化保护继续保留；没有恢复尚未定稿的研究执行方案或执行真实模型。

独立 Python API 只注册登录/会话/改密、人员、V2.0 模版、展会共享库及个人历史统计只读 API、AI 授权代理与执行器窄入口；旧 `/work/bg`、`/bg/`、`/experience/`、`/portal/` 路径不再提供。没有携带原企划项目后端、体验后端或原公共门户。

前端部分未迁移业务仍按 README 的边界保留。未声称已完成调研、企划项目、评审、排期、全部图表或复杂表格业务。没有迁移真实数据或重启现用服务。

源码本身保留有用业务实现；“独立”不等于所有代码都是重写。独立性判断依据是依赖图、启动入口、实际服务和验收结果，不靠替换文件夹名称。
